# 요구사항 명세서 — 화재·가스 감지 자동 대피 유도 시스템

## 1. 프로젝트 목표

화재 발생 초기 징후(온도 상승, 가스 누출, 불꽃)를 센서로 감지하여 경보를 울리고,
비상구를 자동으로 개방하며, LCD로 대피 경로를 안내하고, UART를 통해 PC 관제실에
신고 메시지를 전송하는 임베디드 시스템을 ATmega128 기반으로 구현한다.

## 2. 시스템 구성 개요

```
[온도센서] ─┐
[가스센서] ─┼─ ADC ──┐
[불꽃센서] ─────────┼─→ ATmega128 ──┬─→ 부저 (경보음)
                     │              ├─→ LED (상태 표시)
              (외부 인터럽트)        ├─→ 서보모터 (비상구 개방, PWM)
                                    ├─→ LCD (대피 경로 표시)
                                    └─→ UART → PC 관제실
```

상세 블록다이어그램과 핀맵은 2단계(`docs/architecture.md`)에서 확정한다.

## 3. 입력 정의

| 센서 | 신호 타입 | 인터페이스 | 비고 |
|---|---|---|---|
| 온도 센서 | 아날로그 | ADC 채널 | 임계값 초과 시 "주의" 단계 진입 |
| 가스 센서 (MQ 계열 가정) | 아날로그 | ADC 채널 (온도와 채널 전환) | 임계값 초과 시 "경보" 단계 진입 |
| 불꽃 센서 | 디지털 (HIGH/LOW) | 외부 인터럽트 핀 | 감지 즉시 "경보" 단계 진입 |
| 테스트/리셋 버튼 | 디지털 | GPIO 입력 (풀업, 디바운싱 필요) | 시뮬레이션 시나리오 수동 트리거용 |

## 4. 출력 정의

| 출력 장치 | 인터페이스 | 동작 |
|---|---|---|
| 부저 | GPIO 또는 타이머 PWM | 경보 단계에서 단속음, 대피 단계에서 연속음 |
| LED (상태 표시) | GPIO | 정상(녹색)/주의(노랑)/경보·대피(빨강) |
| 서보모터 (비상구) | 타이머 PWM | 평상시 닫힘 각도, 대피 단계에서 개방 각도로 회전 |
| LCD (16x2 가정) | GPIO 또는 4비트 병렬 | 현재 상태 및 대피 경로 텍스트 표시 |
| UART | USART0, PC 연결 | 경보/대피 진입 시 상태 메시지 1회 전송 |

## 5. 동작 시나리오 (상태 정의)

| 상태 | 진입 조건 | 시스템 동작 |
|---|---|---|
| 정상 | 모든 센서값이 임계값 이하 | LED 정상, LCD "정상 상태", 부저 off, 서보 닫힘 |
| 주의 | 온도 임계값 초과 (가스/불꽃 미감지) | LED 주의, LCD "온도 상승 주의", 부저 간헐음 |
| 경보 | 가스 임계값 초과 또는 불꽃 감지 | LED 경보, LCD "화재 의심, 대피 준비", 부저 경보음, UART로 관제실 알림 |
| 대피 | 경보 상태 N초 지속 또는 복수 센서 동시 임계값 초과 | 서보로 비상구 개방, LCD에 대피 경로 표시, 부저 연속음, UART로 신고 메시지 전송 |

상태 전이 다이어그램은 12단계(화재 판단 알고리즘 및 상태 기계 설계)에서 상세화한다.

## 6. 성능 요구사항

- 센서 폴링 주기: 타이머 기반 주기적 샘플링 (주기는 10단계에서 확정)
- 불꽃 감지 → 경보 반응 시간: 인터럽트 기반이므로 100ms 이내
- 버튼 입력 디바운싱: 최소 20ms
- UART 통신: 관제실 PC와 보드레이트 합의 필요 (13단계에서 확정, 기본값 9600bps 가정)

## 7. 검증 범위 (시뮬레이터 기반)

- 실제 하드웨어 없이 Proteus 또는 SimulIDE 가상 회로로 검증한다.
- 센서 입력은 시뮬레이터 부품으로 대체한다. 온도는 NTC 서미스터(10kΩ, B=3950) + 10kΩ 분압 회로, 가스는 MQ-2 모듈의 아날로그 출력(0~5V)을 흉내 내는 가변 전압원, 불꽃은 스위치(디지털 입력)를 쓴다. (처음에는 온도·가스 모두 가변저항이었으나 2026-11-18 교체)
- 각 상태 전이(정상→주의→경보→대피)를 수동으로 트리거하여 LED/LCD/부저/서보/UART 출력을 확인한다.
- 가능한 경우 목(mock) 입력값 기반 단위 테스트 코드를 함께 작성하여 시뮬레이터 없이도 상태 전이 로직을 점검한다.
