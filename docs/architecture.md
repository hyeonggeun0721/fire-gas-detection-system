# 시스템 아키텍처 및 회로 설계 초안

## 1. 전체 블록다이어그램

```
                    +----------------------------+
  온도 센서 ------->|  ADC0 (PF0)                |
  가스 센서 ------->|  ADC1 (PF1)                |
                    |                            |
  불꽃 센서 ------->|  INT0 (PD0)                |
  테스트 버튼 ----->|  INT1 (PD1)                |
                    |                            |
                    |      ATmega128             |
                    |                            |
                    |  Timer1 OC1A (PB5) --------|-----> 서보모터 (비상구)
                    |  GPIO   (PD4)     ---------|-----> 부저
                    |  GPIO   (PA0-2)   ---------|-----> 상태 LED (정상/주의/경보)
                    |  GPIO   (PC0-5)   ---------|-----> LCD 16x2 (4비트 모드)
                    |  USART0 TXD (PE1) ---------|-----> UART → PC 관제실
                    +----------------------------+
```

- ADC 입력(온도/가스)은 하나의 ADC 모듈을 채널 전환(MUX)하여 순차적으로 읽는다 (8단계에서 구현).
- 불꽃 센서와 테스트 버튼은 외부 인터럽트(INT0/INT1)로 처리하여 폴링 없이 즉시 반응한다 (9단계).
- 서보모터는 Timer1의 16비트 분해능을 이용한 PWM으로 제어한다 (11단계).
- UART는 하드웨어 USART0을 사용하며, PC 쪽은 별도 터미널 프로그램(또는 시뮬레이터의 가상 터미널)로 수신한다 (13단계).

## 2. ATmega128 핀맵

| 핀 | 포트 | 기능 | 방향 | 비고 |
|---|---|---|---|---|
| ADC0 | PF0 | 온도 센서 아날로그 입력 | 입력 | AVCC/AREF 기준전압 사용 (7단계에서 확정) |
| ADC1 | PF1 | 가스 센서 아날로그 입력 | 입력 | 온도와 동일 ADC 모듈, 채널 전환으로 공유 |
| INT0 | PD0 | 불꽃 센서 디지털 입력 | 입력 | 외부 인터럽트, 엣지 트리거 (9단계에서 극성 확정) |
| INT1 | PD1 | 테스트/리셋 버튼 | 입력 (풀업) | 디바운싱 필요 (5단계) |
| PD4 | PD4 | 부저 | 출력 | 소프트웨어 토글 방식 |
| PA0 | PA0 | LED - 정상(녹색) | 출력 | |
| PA1 | PA1 | LED - 주의(노랑) | 출력 | |
| PA2 | PA2 | LED - 경보/대피(빨강) | 출력 | |
| PC0 | PC0 | LCD RS | 출력 | 4비트 모드 |
| PC1 | PC1 | LCD E | 출력 | |
| PC2-PC5 | PC2-PC5 | LCD D4-D7 | 출력 | RW은 GND 고정 (쓰기 전용) |
| OC1A | PB5 | 서보모터 PWM 신호 | 출력 | Timer1, 50Hz, 펄스폭 1~2ms |
| TXD0 | PE1 | UART 송신 (PC 관제실) | 출력 | RXD0(PE0)은 향후 양방향 확장 대비 예약 |

## 3. 포트 할당 근거

- **ADC 입력은 PORTF에만 배치**: ATmega128의 ADC 모듈은 PORTF(ADC0-ADC7)에만 연결되어 있어 선택의 여지가 없다. 온도/가스 두 센서를 채널 0, 1에 배치했다.
- **불꽃 센서·버튼은 외부 인터럽트 핀(PD0/PD1)에 배치**: 화재 감지는 반응 속도가 중요하므로 폴링 대신 하드웨어 인터럽트(INT0/INT1)를 사용해 지연을 최소화한다.
- **서보모터는 Timer1의 OC1A(PB5)에 배치**: 서보 제어에는 정밀한 펄스폭(1~2ms) 생성이 필요한데, ATmega128에서 16비트 타이머인 Timer1이 8비트 타이머보다 분해능이 높아 서보 떨림을 줄일 수 있다.
- **UART는 하드웨어 고정 핀(PE0/PE1) 사용**: USART0의 TXD/RXD는 실리콘 상 고정된 핀이므로 별도 선택 여지가 없다.
- **LED·부저·LCD는 남은 범용 포트(PORTA, PORTC, PD4)에 배치**: 특별한 하드웨어 제약이 없으므로, 배선 정리를 위해 LED는 PORTA에, LCD 제어/데이터 라인은 PORTC에 인접하게 모아 배치했다.

## 4. 다음 단계와의 연결

- 3단계: 위 핀맵을 기준으로 AVR-GCC 프로젝트 스켈레톤과 빌드 환경을 구성한다.
- 7~8단계: ADC 기준전압(AREF/AVCC/내부 기준전압) 및 분주비(prescaler)를 확정한다.
- 9단계: INT0/INT1의 엣지 트리거 방식(상승/하강)과 센서 극성을 확정한다.
